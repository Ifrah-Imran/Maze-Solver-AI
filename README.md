# Maze Solver AI (Pygame)

This project is a Python-based Maze Solver and Pathfinding Visualizer built using Pygame.

## Features
- Interactive maze navigation
- BFS, DFS, UCS, Best-First Search, and A* algorithms
- Terrain with different movement costs
- Real-time performance comparison
- Visual analytics dashboard

## Technologies Used
- Python
- Pygame

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the project:
   python main.py

## Controls
- Arrow Keys → Move player
- Reach the goal to view algorithm comparisons
